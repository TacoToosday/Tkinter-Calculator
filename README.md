# Python Calculator

A simple calculator app built with Python and Tkinter.

## Features
- Basic arithmetic operations: add, subtract, multiply, and divide
- GUI input fields and operation selector
- Result display with validation for invalid input and division by zero

## Requirements
- Python 3.x (tested with Python 3.14)
- Tkinter (included with most standard Python installations on macOS and Windows)

## Installation

Clone the repository and navigate to the project folder:

```bash
git clone https://github.com/TacoToosday/Tkinter-Calculator.git
cd "Tkinter Calculator"
```

Create and activate a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

On Windows PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

## Usage

Run the calculator:

```bash
python main.py
```

Or, if using the virtual environment directly:

```bash
./.venv/bin/python main.py
```
